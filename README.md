# Wedding Invitation Webpage

This project contains the HTML, CSS, and JavaScript files for a wedding invitation webpage. The invitation features the names of the couple, the wedding date, location, and an RSVP link. The design includes custom fonts, colors, and layout to create an elegant and inviting appearance.

## Project Files
- `index.html`: The main HTML file that structures the wedding invitation content.
- `styles.css`: The CSS file that styles the wedding invitation, including layout, colors, and fonts.
- `script.js`: The JavaScript file that may contain any interactive functionality for the invitation (if needed).
